Your Higgsfield API key

  1. Open console.higgsfield.ai and sign in.
  2. Create an API key. You get a key ID and a key secret.
  3. Paste them below and press Save. If you saved the key as one long text, paste all of it in the first box.

Your key is saved only in a file called .env inside this Studio folder on your computer. It is never uploaded to GitHub and never shown to the web page again.
